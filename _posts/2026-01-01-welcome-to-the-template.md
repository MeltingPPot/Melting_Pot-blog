## Markdown and code

The site uses Kramdown and Rouge, so fenced code blocks receive syntax
highlighting:

```javascript
const message = 'Make the template yours.';
console.log(message);
```

f(n) = \sum_{k=0}^{n} k = \frac{n(n+1)}{2}

## Local image

The template keeps its example media inside the repository:

![Template avatar]({{ site.baseurl }}/img/avatar-lab.svg)

To create an encrypted article, open the local admin panel, enable the
encryption option, and save the article. The password never reaches the
Python server or the Git repository.
